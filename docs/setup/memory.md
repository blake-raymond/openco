# Memory

Setup asks you to use `memory/` in your data repo. That is the memory.
You add a new dated file when a session ends. You do not edit an old one.
Nothing is installed.

```markdown
---
date: 2026-11-15
---

# Where we stopped

One short paragraph. Company claims in here also belong in facts.md.
```

## Deferred tools

claude-mem and mem0 are deferred. Setup does not install them, and you
do not install them before `make setup`. They were not verified here.
`memory/` stays the memory either way.

Claude-Mem's introduction, read on 15 Nov 2026, says `npx claude-mem install`
and lists Cursor among supported tools, then tells you to restart Claude
Code. That Cursor claim was not checked here.

Mem0's Claude Code page describes a plugin that needs an API key. It
was not installed here, and this repo does not claim it works in Cursor
or Grok Bot.

Do not put API keys in either repository. A company claim still has to
be a line in `facts.md`.
