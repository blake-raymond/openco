# Calls

Full raw transcripts live here, one dated file each:
`YYYY-MM-DD-slug.md`. Do not edit a call file after it has been
committed. Add a new file for a correction.

Grok Bot is the primary recorder. Any recorder or agent can drop the
same generic transcript into this folder, or into `inbox/` with
`kind: transcript`. Intake copies an inbox transcript here and files
facts and decisions whose source is this file.

The format is documented in the public repo at `docs/setup/calls.md`.
Granola is an optional importer, not the default.

This folder has no sample transcript. Real transcripts stay in the
private data repo.
