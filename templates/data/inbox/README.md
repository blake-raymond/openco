# Inbox

Drop a voice note or any other note here, then run `scripts/intake`
from the public openco checkout. Intake files facts, stories, and
decisions onto a new branch and opens a pull request. It does not
commit to main.

A new note dropped here is gitignored, so it is not committed to main
by accident. The sample note is tracked so the format is visible, and
it is fake. Intake moves a note to `inbox/filed/` on the pull request.
