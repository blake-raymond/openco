# Learnings

When a job finishes, add a new dated file here. Do not edit an older
one. Copy this shape:

```markdown
---
date: 2026-11-15
job: example-job
---

# EXAMPLE: job name

## Worked

What worked.

## Failed

What failed.

## Stop doing

What to stop doing.
```

Company claims in a learning still have to be lines in `facts.md`.
