# How I think, write, and decide

The default second brain is a Notion database. For this setup that
database is the Commonplace book. These markdown notes are the fallback
for a checkout that has no Notion token. The ones shipped here are fake
examples, not that database.

Add a new dated file when the fallback notes change. Do not edit a note
after it has been committed. Snapshots under `notion/` are the exception:
`scripts/export-notion` may rewrite them.

Open the data repo root as an Obsidian vault. `.obsidian/` is already there.
