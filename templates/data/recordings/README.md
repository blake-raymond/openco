# Recordings

One recording per workflow, made while doing the job out loud. Store
the transcript here as `YYYY-MM-DD-slug.md`. Do not edit it after it
is committed. Do not commit a recording to the public openco repository.

After the recording exists, draft these sections in the file, from what
was actually said:

## When to use

## Steps

## Checks

## Mistakes

Then run `scripts/skill-from-recording` from the public checkout. That
opens a pull request in this private repo with one `SKILL.md`. It does
not invent steps by itself.
