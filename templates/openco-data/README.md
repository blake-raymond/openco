# openco-data

This is the private data repository for [openco](https://github.com/blake-raymond/openco).

Keep it private. Do not push it to the public openco repository. The public
repository holds the setup, the rules, and the checks. This one holds the
markdown the company runs on, with git history for every change.

The notes under `second-brain/`, `facts/`, `stories/`, `voice/`,
`company-brain/`, and `transcripts/` that ship with the skeleton are
fake examples. They contain the word EXAMPLE. Leave them in place and
append real dated entries after them. Do not edit an example, and do not
edit any entry after it has been committed.

Open `second-brain/` as an Obsidian vault if you want the personal notes
in Obsidian. Company records stay in the other folders.

Proprietary skills live in `skills/`. Shareable skills are copied into
the public repository later, on purpose, and not by default.
