# Company brain

Customers, calls, numbers, pricing, playbooks, and past decisions.

| Kind | Where it lives |
| --- | --- |
| Customers | `customers/` |
| Calls and meetings | `../transcripts/` (see `calls/README.md`) |
| Numbers | `numbers/`, and the sayable figure also in `../facts/FACTS.md` |
| Pricing | `pricing/`, and the sayable price also in `../facts/FACTS.md` |
| Playbooks | `playbooks/` |
| Decisions and why | `decisions/DECISIONS.md` |

Add a new dated file for a customer, number, price, or playbook. Do not
edit a file after it has been committed. An agent still may not say a
number or a price unless that sentence is an entry in the facts file.
