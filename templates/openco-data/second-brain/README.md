# Second brain

Open this folder as an Obsidian vault. Notes are plain markdown with
dates in the file name and in frontmatter. Wikilinks use the file name
without `.md`.

These pages are a fake example of how a person thinks, writes, and
decides. Real notes are new dated files. Do not edit a note after it
has been committed. Do not put company records in this folder; those
belong in the company brain, the facts file, and the other logs.
