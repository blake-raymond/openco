# Voice file

Three append-only lists:

- `best.md` — posts worth imitating. The operating target is 50.
- `hate.md` — posts you do not want repeated. The operating target is 20.
- `never-use.md` — words and phrases that stay unused.

This skeleton has one fake example in each file. Append real dated
entries at the end. Do not edit an earlier entry. The counts above are
the target for a real voice file, not a quota the checker enforces.
